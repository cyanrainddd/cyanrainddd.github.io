一、MISC

1、海报泄露

题目中描述：有人把”内部物料”塞进了一张海报的文件本身，而钥匙又藏在另一张海报里。

  • 打开虚拟机，直接binwalk *.png,发现图片10里有压缩包
  • 于是，用dd命令提取出压缩包并尝试解压

strings *.png notice.txt | grep -i -E “pass|key|isctf|flag|2026”

for i in 01 02 03 04 05 06 07 09 10; do echo “=== Checking poster_$i.png ===”; zsteg -c r -b 1 poster_$i.png; done

from deepseek_tokenizer import ds_token

题目中 assistant 返回的 token ID 序列

token_ids = [19923, 14, 11014, 16, 455, 1926, 3676, 4230, 22651, 4374, 1465, 14, 554, 61932, 16, 5592, 344, 782, 14364, 28, 4756, 5272, 40, 39296, 18, 77, 21, 80, 19, 92, 21, 84, 20627, 21, 88, 21, 84, 17239, 907, 85, 65, 939, 24, 95]

将 ID 序列解码为文本

decoded_text = ds_token.decode(token_ids)
print(“解码结果：”, decoded_text)

pip install deepseek_tokenizer -i https://pypi.tuna.tsinghua.edu.cn/simple/

- 运行脚本即可得出flag
![flag](/images/7.3.2.png)

# 二、Other
## 1、失落的灯标
> 下载完附件，发现一张粉色墙和一个txt文件
![flag](/images/7.4.1.png)
- 首先看txt文件，白色闪光，每组两次，四分一分钟为周期
- 则灯光特征为：`Fl（2） W 15s`
![txt](/images/7.4.2.png)
- 然后去查找这张图片，根据txt文件中提示，*加勒比海*，搜索*粉色圆形塔身，下部为古老砖石结构*
- 可以搜到小库拉索灯塔`Klein Curaçao Lighthouse`与图片比较相似
![灯塔](/images/7.4.3.png)
- 再看由txt得出的灯光特征
- 可以确认是小库拉索灯塔`Klein Curaçao Lighthouse`
![确认](/images/7.4.4.png)
flag为正式名称及对应的航标编号（全大写，_代替空格，删去方位后缀）
所以得到`ISCTF{KLEIN_CURACAO_16054}`

# 三、Web
## 1、git_leak
> 根据题目，发现可能是git泄露的题
- 首先准备git泄露的工具，在github上下载GitHack
- 然后，下载附件，搭建靶场`http://127.0.0.1:8000/`，开始攻击
> 1.进入附件gitleak-attachment目录下cmd，执行`python -m http.server 8000` *这个终端相当于靶场服务器，不可关闭*
![flag](/images/7.7.1.png)
> 2.在工具githack文件目录下cmd， 执行`python GitHack.py http://127.0.0.1:8000/.git/抓取源码` *开始执行githack攻击*
![flag](/images/7.7.2.png)
- 接着，攻击结束，出现一个以端口号为名的文件夹，打开这个文件，就有flag
`ISCTF{Git_136c_1s_34sy_s1gn}`
![flag](/images/7.7.3.png)
---
## 2.Break Here
- 打开靶场，进入一个校验页面有个flag，估计是假的
- 查看页面源码会发现，果然是一个假的flag
![flag](/images/7.8.1.png)
- 这里的 "bp"，指向了 “断点”，所以这题可能是找bp然后发现flag
- 打开F12，发现有个app.js尝试在里面找到解码器
- 找特征`TextDecoder`和`atob`的函数都是`_0x4daeb8`，所以暂时认为这是解码器
![flag](/images/7.8.2.png)
- 于是，在`_0x4daeb8`打一个点，接着刷新执行，flag就出来了
![flag](/images/7.8.3.png)
![flag](/images/7.8.4.png)
