一、MISC

1、海报泄露

题目中描述：有人把”内部物料”塞进了一张海报的文件本身，而钥匙又藏在另一张海报里。

  • 打开虚拟机，直接binwalk *.png,发现图片10里有压缩包
  • 于是，用dd命令提取出压缩包并尝试解压
    dd if=poster_10.png of=hidden.zip bs=1 skip=2655915
    unzip hidden.zip
  • 发现要输入密码，没法直接解开
  • 题目中说钥匙在另一张海报里，所以尝试用string提取关键字
    strings *.png notice.txt | grep -i -E "pass|key|isctf|flag|2026"
  • 发现有KEY的提示：检查图片的红色通道（red channel）的 LSB（最低有效位，1bit）
    用zsteg来做

    由于虚拟机里还没下zsteg，所以重新安装一下，sudo gem install zsteg

  • 使用这个循环遍历剩下的所有图片
    for i in 01 02 03 04 05 06 07 09 10; do echo "=== Checking poster_$i.png ==="; zsteg -c r -b 1 poster_$i.png; done
  • 得到了一个关键提示

    text: “wfake_zip_do_not_bruteforce\nthe zip is PRETEND-encrypted:\nflip the general purpose bit fla k to 0 and just extract.\n”

  • 可以发现，这是个伪加密，需要把“通用标志位”翻转成0，然后直接解压。
  • 使用hexedit修改标志位，一般是头一个尾一个

    本地文件头:搜50 4B 03 04：往后数4个字节（2字节版本号），看到01 00就改成00 00
    中央目录文件头:搜50 4B 01 02：往后数6个字节（2字节创建版本+2字节解压版本），看到01 00就改成00 00。

  • 然后就得出flag的图片了
    ISCTF{p0st3r_LSB_1END_z1p_w1th_pr3t3nd_p4ss}

2、人民铁路为人民

歌是改编自100年前的日本歌曲,请说出原歌曲名(一个pcap文件)
距离这个图片的所在地最近的，而且在这首歌中提到的车站名。

  • 根据题目，应该从pcap变成音频文件，所以在wireshark中导出音频
  • 因为全是一模一样的UDP包，并且长度都是固定的Len=894，所以暂时推测是RTP
  • 任选一条，右击Decode As,编码修改成RTP
  • 如图将音频Play Streams导出
  • 音频导出成功后，根据听歌识曲，发现是洛天依唱的《铁道唱歌·京广高铁篇》，原曲为《铁道唱歌》
  • 而附件中的图片是开封的大宋酒
  • 距离开封最近且歌曲中提到的站点应该是，郑州东站，由此得出flag
    ISCTF{铁道唱歌_郑州东站}

3、我是克劳德？

  • 下载附件可以得到一个py文件，打开发现底层调用的仍然是deepseek模型
  • 发现有一串凭证数字，应该是Token ID序列
  • 所以编写一个脚本solve.py,用DeepSeek的Tokenizer进行解码。

在文件夹内打开终端,安装并激活虚拟环境
python -m venv venv
.\venv\Scripts\Activate.ps1
安装库
pip install deepseek_tokenizer -i https://pypi.tuna.tsinghua.edu.cn/simple/

  • 运行脚本即可得出flag

二、Other

1、失落的灯标

下载完附件，发现一张粉色墙和一个txt文件

  • 首先看txt文件，白色闪光，每组两次，四分一分钟为周期
  • 则灯光特征为：Fl（2） W 15s
  • 然后去查找这张图片，根据txt文件中提示，加勒比海，搜索粉色圆形塔身，下部为古老砖石结构
  • 可以搜到小库拉索灯塔Klein Curaçao Lighthouse与图片比较相似
  • 再看由txt得出的灯光特征
  • 可以确认是小库拉索灯塔Klein Curaçao Lighthouse

    flag为正式名称及对应的航标编号（全大写，_代替空格，删去方位后缀）
    所以得到ISCTF{KLEIN_CURACAO_16054}

2、彩蛋题：小蓝鲨寻宝记

附件打开，一个带锁宝箱和一个html网页

  • 正常玩网页小游戏通关之后，会弹出前半段密码Shark_Says_
  • 按照提示进入官网，得到后半段密码AhWu_2026
  • 解压宝箱压缩包，得到flag

三、Web

1、git_leak

根据题目，发现可能是git泄露的题

  • 首先准备git泄露的工具，在github上下载GitHack
  • 然后，下载附件，搭建靶场http://127.0.0.1:8000/，开始攻击

    1.进入附件gitleak-attachment目录下cmd，执行python -m http.server 8000 这个终端相当于靶场服务器，不可关闭

    2.在工具githack文件目录下cmd， 执行python GitHack.py http://127.0.0.1:8000/.git/抓取源码 开始执行githack攻击

  • 接着，攻击结束，出现一个以端口号为名的文件夹，打开这个文件，就有flag
    ISCTF{Git_136c_1s_34sy_s1gn}

2.Break Here

  • 打开靶场，进入一个校验页面有个flag，估计是假的
  • 查看页面源码会发现，果然是一个假的flag
  • 这里的 “bp”，指向了 “断点”，所以这题可能是找bp然后发现flag
  • 打开F12，发现有个app.js尝试在里面找到解码器
  • 找特征TextDecoder和atob的函数都是_0x4daeb8，所以暂时认为这是解码器
  • 于是，在_0x4daeb8打一个点，接着刷新执行，flag就出来了
